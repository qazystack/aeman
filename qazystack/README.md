# qazystack/aeman

A fork of [aenix-io/aeman](https://github.com/aenix-io/aeman) (Apache-2.0). It exists to carry a few additions until they are
accepted upstream or rejected; everything generic is offered upstream as a draft PR.

- `main` = upstream `main` + this folder. Upstream is merged in regularly; nothing else of ours lands on `main` except merged PRs.
- This folder (`qazystack/`) holds the fork's own notes: the plan (`ROADMAP.md`) and the developer rules (`DEVELOPER.md`).
- The repository is public. It holds no deployment details of anyone using it.
